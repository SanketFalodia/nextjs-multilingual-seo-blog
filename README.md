# 🌐 Multilingual SSG Blog with AI-Powered SEO

Welcome to the **Next.js Multilingual SEO Blog**! This project is being engineered as a take-home technical assignment for the Web Development & AI-Powered SEO Intern role. It is a highly optimized, statically generated multilingual blog built to automate content translation and implement advanced technical SEO architecture.

## ✨ Planned Features & Milestones

- [x] **🏗️ Base Architecture Setup:** Next.js scaffolding initialized with structural Tailwind CSS layout mechanics.
- [ ] **⚡ 100% Static Site Generation (SSG):** Dynamic post mapping via `generateStaticParams` to build pure HTML/JSON files at compile time.
- [ ] **🤖 Automated Multilingual Pipeline:** Node.js pre-build translation engine to automatically generate Hindi (`/hi/[slug]`) variations from a single English JSON entry.
- [ ] **📈 High-Tier Technical SEO:** Complete optimization including precise dual-language `hreflang` structural maps, canonical URLs, dynamic `sitemap.xml`, and `robots.txt`.
- [ ] **☁️ Edge Infrastructure Deployment:** Continuous integration via Cloudflare Pages with automatic redeploys on every GitHub push.

## 🛠️ Tech Stack & Workspace Blueprint

- **Framework:** Next.js (App Router)
- **Styling UI:** Tailwind CSS (Clean, minimalist typography)
- **Hosting Tier:** Cloudflare Pages (Free Edge Network Tier)
- **Data Source:** Local flat-file JSON dataset (`data/posts.json`)

## 🚀 Getting Started (Local Development)

Follow these steps to spin up the local workspace workspace environment:

### 1. Clone the Repository
```bash
git clone https://github.com.git
cd nextjs-multilingual-seo-blog
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Launch Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your web browser to view the application layer.
